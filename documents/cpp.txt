================================================================================
                        C++ PROGRAMMING LANGUAGE
================================================================================

1. INTRODUCTION
---------------
C++ is a general-purpose, statically-typed, compiled programming language. It was
designed by Bjarne Stroustrup in 1979 as an extension of the C language with
object-oriented features. Since then, it has evolved significantly, incorporating
generic programming, functional programming, and low-level memory manipulation.

Key design principles:
- Zero-overhead abstractions – use abstractions without sacrificing performance.
- Direct hardware access – allows manipulation of memory, registers, and system
  resources.
- Multi-paradigm – supports procedural, object-oriented, generic, and functional
  programming styles.

C++ is widely used in systems programming, game development, embedded systems,
high-performance computing, and large-scale applications.

2. BASIC SYNTAX AND STRUCTURE
-----------------------------
A typical C++ program consists of:
- Preprocessor directives (e.g., #include, #define)
- Namespace declarations (e.g., using namespace std;)
- Function definitions (including main())
- Classes and structures
- Templates and inline functions

Example:
    #include <iostream>
    int main() {
        std::cout << "Hello, World!" << std::endl;
        return 0;
    }

3. OBJECT-ORIENTED PROGRAMMING (OOP) FEATURES
----------------------------------------------
C++ supports the four pillars of OOP:
- Encapsulation: using classes to bundle data and methods; access specifiers
  (public, private, protected) control visibility.
- Inheritance: derive new classes from base classes, supporting single and
  multiple inheritance.
- Polymorphism: compile-time (function overloading, operator overloading) and
  run-time (virtual functions, abstract classes).
- Abstraction: interfaces via pure virtual functions.

4. STANDARD TEMPLATE LIBRARY (STL)
-----------------------------------
The STL is a powerful library providing generic containers, iterators, algorithms,
and function objects.
- Containers: vector, deque, list, set, map, unordered_map, etc.
- Iterators: allow traversal of containers; categories: input, output, forward,
  bidirectional, random-access.
- Algorithms: sort, find, accumulate, transform, etc.
- Function objects (functors) and lambda expressions (since C++11).

5. MEMORY MANAGEMENT
---------------------
C++ gives explicit control over memory:
- Stack vs. Heap: local variables on stack; dynamic allocation with new/delete.
- Smart pointers (C++11): unique_ptr, shared_ptr, weak_ptr for automatic
  resource management (RAII).
- Custom allocators and placement new.

6. MODERN C++ FEATURES (C++11,14,17,20,23)
-------------------------------------------
- C++11: auto type deduction, range-based for loops, move semantics, rvalue
  references, lambda expressions, constexpr, static_assert, threading support.
- C++14: generalized lambda captures, binary literals, decltype(auto).
- C++17: structured bindings, if constexpr, filesystem library, parallel
  algorithms, std::optional, std::variant.
- C++20: concepts, coroutines, ranges, three-way comparison (<=>), designated
  initializers, std::span.
- C++23: deducing this, std::expected, standard library modules (partial).

7. CONCURRENCY AND PARALLELISM
-------------------------------
C++ provides native threading:
- std::thread, std::jthread (C++20)
- Mutexes, condition variables, atomic operations.
- Async/future for task-based parallelism.
- Parallel algorithms (C++17): execution policies (seq, par, par_unseq).

8. TEMPLATES AND GENERIC PROGRAMMING
-------------------------------------
Templates allow generic code with types as parameters:
- Function templates and class templates.
- Template specialization (full and partial).
- Variadic templates (C++11).
- Concepts (C++20) to constrain template arguments.

9. EXCEPTION HANDLING
---------------------
C++ uses try-catch blocks for error handling:
- throw exceptions to signal errors.
- Standard exception hierarchy (std::exception, std::runtime_error, etc.).
- noexcept specifier for move constructors/assignments.

10. BUILD TOOLS AND ECOSYSTEM
------------------------------
- Compilers: GCC, Clang, MSVC.
- Build systems: CMake, Make, Bazel.
- Package managers: Conan, vcpkg.
- IDE: Visual Studio, CLion, VS Code with extensions.

11. BEST PRACTICES
-------------------
- Use RAII for resource management.
- Prefer smart pointers over raw pointers.
- Use const correctness.
- Avoid global variables and macros.
- Follow the Rule of Zero/Five.
- Use namespaces to avoid name collisions.
- Write unit tests using Google Test, Catch2, etc.

12. PERFORMANCE TIPS
--------------------
- Use move semantics to avoid copies.
- Reserve capacity in containers when size known.
- Use references and const references for function parameters.
- Avoid dynamic_cast in performance-critical paths.
- Profile and optimize hot paths.

13. COMMON USE CASES
--------------------
- System software (OS kernels, drivers, compilers).
- Game engines (Unreal, Unity).
- High-frequency trading systems.
- Scientific computing and simulation.
- Robotics and autonomous vehicles.
